Política de Privacidade

Última atualização: 2026

Esta política explica como o RicCoin, mantido pelo Grupo Riccieri, trata as informações dos visitantes deste site.

1. Dados que coletamos

O RicCoin não exige cadastro, login ou envio de dados pessoais para uso. Suas moedas favoritas são salvas apenas localmente no seu próprio navegador (não são enviadas para nossos servidores).

2. Cookies e publicidade

Este site utiliza o Google AdSense para exibir anúncios. O Google e seus parceiros podem usar cookies e identificadores para exibir anúncios personalizados com base nas suas visitas a este e outros sites.

Se você está localizado no Espaço Econômico Europeu, Reino Unido ou Suíça, um banner de consentimento é exibido para que você possa aceitar, recusar ou gerenciar suas preferências de cookies antes de qualquer anúncio personalizado ser carregado.

Você pode saber mais sobre como o Google usa dados de sites parceiros e ajustar suas preferências de anúncios em: policies.google.com/technologies/partner-sites

3. Dados de terceiros

Os preços de criptomoedas exibidos são obtidos da API pública da CoinGecko. Essa consulta é feita diretamente pelo seu navegador; não armazenamos nem processamos esses dados em nossos próprios servidores.

4. Seus direitos

Você pode, a qualquer momento, limpar os dados salvos localmente pelo RicCoin (como favoritos) apagando os dados de navegação do seu navegador para este site. Para dúvidas sobre esta política, entre em contato pelos canais informados na página Sobre.

5. Alterações nesta política

Esta política pode ser atualizada periodicamente para refletir mudanças no funcionamento do site ou em exigências legais. Recomendamos revisá-la de tempos em tempos.
